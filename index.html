Image Steganography Toolkit

A front end for steganographic operations on image files. Each operation runs server-side against a Kali utility. Pick an operation to begin.

📥Embed

Hide a secret file inside a cover image (JPEG/BMP) or audio carrier, optionally with a passphrase.

📤Extract

Pull a hidden payload back out of a stego file using the passphrase it was embedded with.

🔎Detect

Scan a file for signs of embedded content without trying to recover it.

🔑Crack

Run a wordlist against a stego file to recover an unknown passphrase.
